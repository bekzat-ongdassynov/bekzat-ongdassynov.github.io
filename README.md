# bekzat-ongdassynov.github.io

Personal site — static, no build step. Served by GitHub Pages from the repository root.

```
index.html    markup and content
styles.css    design tokens, layout, components
script.js     scroll spy and mobile navigation
pfp.jpg       portrait
```

## Profile picture

The portrait is `pfp.jpg` in the repository root. If it fails to load, the frame
falls back to an initials monogram.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
